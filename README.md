# Trace iOS Card Stitch v9

正式版本号：v9。

本次 v9 更新：
- 备份与恢复面板修正小屏幕显示与底部安全区，列表可完整滚动；同一面板直接提供导出 JSON、导入 JSON。
- 字卡 JSON 导入兼容扩展：支持 Trace 原版字卡数组、整站备份的 `cards` / `wordCards`，以及常见 reply-groups 的 `customReplyGroups` + `items` 结构，并保留分组名称。
- 字卡区整理为“导入字卡 / 导出字卡”。点击“导出字卡”会弹出 iOS 风格选项，可选择导出 JSON，或把全部字卡按一条一行复制到剪贴板；导出 JSON 同时包含 Trace `cards` 和 reply-groups 兼容字段。
- 取消可见的“连发模式”开关。发送键单击只发送消息；双击完成这一轮并触发角色回复，可连续单击多条后再双击结束。
- 私聊输入框改为原生 `textarea`，占位提示为“单击发送 · 双击完成并回复”，并增强 iOS 主屏幕 Web App 键盘兼容性。
- 升级时自动清理旧连发模式遗留的 `[未发送]` 草稿标记。

v8 的角色备注、头像修改、严格字卡绑定与拼字卡上限修复继续保留。
