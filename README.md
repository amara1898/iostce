# Trace iOS Card Stitch v11

正式版本号：v11。

本次 v11 更新：
- 群聊回复速度与设置中的“最快响应 / 最慢响应”完全共用；同一轮参与回复的角色各自独立随机等待，不再按角色强行排先后。
- 群聊消息气泡与单聊统一：字号、行高、内边距、圆角、尾巴和时间戳布局使用同一套 iMessage 视觉规格。
- 底部“角色”页新增独立“群聊”分类，角色与群聊统一集中管理。
- 群聊资料页支持修改群聊名称与自定义群头像；修改结果同步到信息列表和群聊顶部。
- 群聊资料页新增“群内气泡数排名”，按每个角色在这个群聊里实际发送的气泡数量从高到低排序，并显示其占全部角色气泡的比例。
- 字卡管理新增“清理重复”：只清理由“同一分组 + 完全相同文字”产生的多余副本；不同分组里的同一句话会保留。手动注入会直接跳过重复，移动分组若产生重复会自动清理。

v10 的多角色日记、慢信收件人、多角色独立信箱、日记提醒蓝点与日记/回信字卡条数上限设置继续保留。
