# Trace v11

iOS Messages 风格 Trace 网页应用。

v11 核心：群聊归入角色页独立分类与资料管理；群名称/头像可编辑；群内按角色实际发送气泡数排行；群聊气泡视觉与单聊统一；群聊回复速度读取最快/最慢响应设置；字卡重复清理；日记/慢信多角色与字卡条数设置；字卡 JSON 兼容导入导出；单击发送、双击直接触发回复（无需先发消息）。

v11-r4 修复：群聊发送键接入与单聊一致的单击/双击手势；群消息由整页重绘改为增量插入，同时合并短时间内的保存和会话列表刷新，降低长群聊连续发送时的卡顿。

部署：将本目录 7 个文件全部上传到 GitHub Pages 仓库根目录，保持 `index.html` 在根目录。

v11-r5 修订：单聊与群聊的双击发送键改为独立“触发回复”动作；输入框为空、这一轮没有先发送文字时也可直接双击让角色回复。

### v11-r6 修订
- 慢信寄信改为两步：先在独立页面选择一个或多个收件人，再进入独立写信页。
- 写信页不再显示角色列表；底部固定保留“寄出”按钮，避免小屏幕滚动后找不到发送入口。
