# Trace iOS Card Stitch v10

正式版本号：v10。

本次 v10 更新：
- 交换日记改为按角色独立保存；不同角色不再共用同一份 Ta 日记。
- Ta 的日记与慢信回信都严格使用当前角色已绑定的字卡组。
- 「日记与慢信」内部新增「Ta 的字卡条数」设置：日记和回信可以分别设置最多使用多少条字卡，范围 1–100；默认保持原来的日记 4 条、回信 2 条，实际生成时随机抽取且不会重复，也不会超过当前角色可用字卡数量。
- 写信页新增多角色收件人选择：可一次勾选多个角色；同一封正文会分别寄入每个角色的独立信箱，每位角色用自己的绑定字卡生成自己的回信，并拥有独立的 12–36 小时随机送达时间。已有回信在途的角色会暂时显示为不可重复寄送。
- 每个角色每天独立决定是否写日记，并安排 09:00–22:59 的随机写作时间；Trace 仍在后台存活时会自动检查，iOS 将网页挂起后会在下次打开时补检查。
- 有新日记时，底部「功能」、功能页「交换日记」以及对应角色旁显示 iOS 蓝点；打开该角色日记后清除该角色蓝点。
- 旧版无法识别归属的历史日记首次升级时归到当前角色，避免继续被所有角色共用。

v9 的系统通知、字卡 JSON 兼容、导入导出、单击/双击发送与原生 textarea 输入框继续保留。
