# Trace v12

内部修订：v12-r20。

本次更新：

- 新增默认关闭的低概率角色撤回，可选 0.5% / 1% / 2%；只撤回角色刚发出的普通文字或表情。
- 回复条数改为最少/最多区间；两项相同时仍严格固定条数。
- 本地表情导入保留 GIF、WebP 与 APNG 动画；单聊和群聊输入区都有表情快捷按钮。
- 修复状态混入会被刷新强制关闭的问题；状态按行填写，可显示 Emoji 或“正在工作”等文字，名字下方使用小号状态。
- 表情分组可在角色管理中逐角色绑定；清空后该角色不会主动发表情。
- 回复设置标记为通用，不再显示当前角色名。
- 慢信收纳盒改为系统级，统一显示所有角色来信；功能页取消蓝点，未读蓝点显示在对应角色行。
- 保留 v12 统一来电池、多人竞争/合家欢、多人通话最小化、群聊主动呼出、问卷与拍一拍。
- 保留 r8 键盘行为、r9 日记/慢信自然排列；未重新应用此前暂缓的 r6 stitch strict-max 行为。
- Tips「最近更新」固定 5 行未改。

部署：将目录 7 个文件全部上传到 GitHub Pages 仓库根目录，确保 index.html 位于根目录。


## r16 更新

- 状态栏支持文字、纯 Emoji 与颜文字；句子混入仍只使用不含文字的项目。
- 慢信未读蓝点只显示在底部“功能”和功能页“交换日记”一行，不再关联角色页或聊天页。
- 来电页改为全屏，通话页采用简洁的 FaceTime 风格成员卡片；背景从头像提取色系，不调用摄像头或麦克风。
- 合家欢模式在通话页显示邀请入口，多人竞争模式隐藏邀请入口。


## r20 更新

- 单聊顶部头像和对方消息头像可双击拍一拍。
- 每个角色独立记住当前拍一拍文案；每次拍一拍仅约 3% 概率从拍一拍池换成另一条。
- 单聊拍一拍后延续群聊逻辑，随机触发 Ta 发消息、Ta 拍你一下或低概率来电。
- 功能页“交换日记”改名为“信箱”；信件未读蓝点只显示在底部“功能”和功能页“信箱”一行。

- r20：系统级信箱的交换日记页增加独立角色选择；查看、写入与心情统计不再跟随当前聊天角色。
- r20：单聊支持用户引用任意消息，角色会低概率引用用户近期消息；媒体与问卷取消普通气泡外壳。
- r20：对方头像略微放大并清除边框遮挡；开启时间戳时上移时间并收紧额外气泡高度。

- r20：群聊支持引用，但引用目标严格限制为用户消息；角色低概率引用用户近期群消息，角色之间不会互相引用。

- r20：动图表情按 MIME、扩展名和文件头识别并保留原始动画；系统提示、分组标签和功能模块统一为无黑框的 iOS 样式；所有功能入口使用完整页面，专注页不再露出底层功能页。
