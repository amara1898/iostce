# Trace iOS v10

本版修正：
- 未读蓝点在打开并阅读对话后立即消失；聊天打开时收到的新消息直接视为已读。
- “正在输入”改成 iMessage 三点明暗动画气泡。
- 侧边“急救”改成 iOS 圆角/医疗十字样式。
- 统一剩余像素感控件：顶部提示、滑杆圆形旋钮、勾选框、上下文菜单、加载按钮等。
- 修复词库首选项遮挡与角色面板无法滚到底，加入安全区底部留白。
- 信息页“编辑”改成真正的对话选择/删除；删除聊天记录但保留角色。
- 删除信息页右上角错误的分享/角色面板按钮。
- 设置页移除顶部“我 / Trace · 聊天与角色设置”卡片、移除“角色与聊天”与“Trace”关于项。

其余 v9 功能（角色绑定字卡组、词库拼字卡、iOS 通话/视频通话、时间戳等）保留。
