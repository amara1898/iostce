Trace iOS System Theme v19

v19 修正聊天页顶部材质：
- 聊天内容区恢复接近 iMessage 的白色，不再整页发灰。
- 顶部头像/名字/通话栏改为真正覆盖在聊天内容之上的半透明毛玻璃。
- 消息可从顶栏下方滚过，因此 backdrop-filter 能实际模糊后面的内容，而不是单纯涂一层灰色。
- 底部输入栏同步使用轻微半透明材质。
- 保留 v18 的悬浮球、提示、备份、群聊、关系页等功能。

部署：将本目录全部文件上传到 GitHub Pages 仓库根目录并覆盖旧文件；不要删除主屏幕上的旧 App。


v20: 底部导航栏改为 iOS 风格浅灰半透明材质，保留毛玻璃与深色模式。
