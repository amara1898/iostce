# Trace v12

内部修订：v12-r14。

本次更新：

- 主动来电统一为手机级来电池；新增“多人竞争 / 合家欢”切换。竞争模式只能接一人，合家欢会合并时间重叠的独立来电；群聊电话按钮改为主动呼出，不再随机制造角色来电。

- 多人通话新增与单聊一致的缩小按钮和可拖动悬浮条；显示成员、人数、实时通话时长，点击恢复，缩小不打断通话。

- 每个回复气泡独立选择文字或表情：表情保持 8% 低概率并始终单独成条，不再自动生成文字＋表情；未选择角色表情分组时默认使用全部已添加表情。
- “单次回复”改为确定条数；设为 3 时，单聊、群聊和拼字卡模式每轮均生成 3 个气泡。
- 群聊消息增加成员头像；双击成员头像会触发“拍一拍”系统提示，并只让被拍成员随机发信息、拍用户一下，或在允许主动来电时拨来电话。
- “拍一拍”动作库移动到「设置 → 首选项 → 参数」，继续使用原有 `customPats` 数据。
- 每个轮到回复的角色各自有 3% 低概率附加触发主动来电，不会吞掉原定回复；所有角色共用同一来电池，同时来电按“多人竞争 / 合家欢”设置决定选一人接听或合并通话。
- 单聊聊天页顶部改为备注名优先，无备注时显示角色本名。
- v12 版本说明补入以上功能；「提示 → 最近更新」固定 5 行未改。

保留内容：

- r8：iOS 键盘打开时发送后保持；键盘已收起时发送不自动弹出。
- r9：日记与慢信回信按自然段排列。
- 未重新应用此前暂缓的 r6 stitch strict-max 行为。

部署：将本目录 7 个文件全部上传到 GitHub Pages 仓库根目录，确保 `index.html` 位于根目录。
