# Trace v12

iOS Messages 风格 Trace 网页应用。

v12 新增「问卷」：
- 私聊左下角「＋」新增问卷。题目可自定义，选项可自行添加或删除；发出后 Ta 会在当前“最快响应 / 最慢响应”范围内随机选择。
- 群聊输入区也新增「＋」和问卷。问卷发到群里后，每个群成员都会独立随机选择一个选项，结果直接汇总在同一张问卷卡片里。
- 私聊问卷可以切换到「让 Ta 出题」：题目从当前角色自己绑定的字卡中随机抽 1 条，选项再从同一角色字卡中随机抽 2–5 条，且不会和题目重复。
- 可选开启「Ta 偶尔主动问我」。概率可选 5% / 10% / 20%，默认 10%；每次触发 Ta 回复时检查一次，命中后这一轮改成问卷，并有 30 分钟冷却避免连续刷问卷。
- 问卷等待中的随机选择会记录预计完成时间；如果 iOS 中途挂起网页，重新打开后会补完成已经到时间的选择。

同时保留 v11 的群聊管理、群名称/头像、群内角色气泡数排行、群聊性能优化、重复字卡清理、慢信多角色、日记与字卡条数设置，以及单击发送 / 双击直接触发回复。

- 「提示」已补充今天新增的主要功能：双击触发回复、问卷、群聊管理、日记与慢信、字卡整理。

部署：将本目录 7 个文件全部上传到 GitHub Pages 仓库根目录，保持 `index.html` 在根目录。
