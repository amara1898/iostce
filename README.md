# iOS 主题 · v2

本版在上一版基础上继续修正 iPhone 全屏体验：

- viewport 增加 `viewport-fit=cover`，iOS 安全区可正确生效。
- 聊天输入栏和底部导航给 Home Indicator 预留真实安全区，避免最下面被挡住。
- 「信息」主页改为原生 Messages 那种连续列表底色：会话项不再是一条条白色卡片/白条。
- 保留上一版的「回复设置 → 拼字卡」功能及原 Trace 功能。


## v3 本次更新
- 聊天右上角通话按钮现在可选择“音频通话 / 视频通话”。
- 视频通话是纯 UI 模拟窗口，不调用 getUserMedia，不请求摄像头或麦克风权限。
- iMessage 气泡默认不显示内部时间。
- 设置 → 聊天新增“时间戳”开关；开启后时间以 HH:MM 小字显示在气泡右下角。
